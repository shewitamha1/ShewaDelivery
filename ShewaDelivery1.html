System Design

Microservices Architecture

Six independent layers communicate asynchronously via RabbitMQ events and synchronously through a unified API Gateway — each layer independently deployable and horizontally scalable.

📱
Mobile & Web UI

React Native (Expo) for iOS/Android and React.js for the web. TypeScript throughout for type safety and developer ergonomics.

React NativeTypeScriptTailwind
🔀
API Gateway

Nginx reverse proxy with JWT middleware handles all external traffic. Rate limiting at 100 req/min per client IP prevents abuse.

NginxJWT AuthRate Limiting
⚙️
Backend Services

Six isolated Node.js microservices: Order, User, Driver, Restaurant, Payment, and Notification — each with its own data store.

Node.jsExpress.jsMicroservices
📨
Message Broker

RabbitMQ on Amazon MQ decouples services with AMQP events. Order events propagate to all consumers within 500ms guaranteed.

RabbitMQAmazon MQAMQP
🗄️
Data Layer

PostgreSQL on RDS for transactional data, MongoDB Atlas for geo-spatial GPS documents, Redis for sub-millisecond session caching.

PostgreSQLMongoDBRedis
☁️
DevOps / Infra

Kubernetes on AWS EKS with GitHub Actions CI/CD pipelines. Terraform manages infrastructure as code. CloudWatch for observability.

AWS EKSTerraformCI/CD

Technology Choices

Full-Stack Environment

Each technology chosen to serve specific Architecture Significant Requirements — performance, availability, and scalability under Ethiopian network conditions.

⚛️
React Native
Mobile Frontend
Expo-managed workflow enables 60fps on low-cost Android devices prevalent in Mekelle. Shared codebase reduces delivery time by ~40%.
🟢
Node.js + Express
Backend Services
Non-blocking I/O handles 10,000+ concurrent WebSocket connections critical for live GPS updates without thread overhead.
🐘
PostgreSQL
Primary Database
ACID compliance ensures payment and order integrity. AWS RDS Multi-AZ supports 99.9% availability SLA with automatic failover.
🍃
MongoDB Atlas
GPS Document Store
Native geospatial indexes ($near, $geoWithin) make Haversine-based driver queries sub-10ms — critical for the 10s assignment target.
🐇
RabbitMQ
Message Broker
AMQP with durable queues guarantees no order event loss on service crash. 500ms propagation SLA is achievable with direct exchanges.
⚡
Redis
Cache Layer
Session tokens and restaurant menus cached with TTL, reducing PostgreSQL reads by ~65%. In-memory delivery stays under 2ms P99.
☸️
AWS EKS
Container Orchestration
Kubernetes HPA auto-scales driver service pods during peak hours (18:00–21:00 local). Zero-downtime rolling deployments via CI/CD.
🔧
Terraform
Infrastructure as Code
Declarative IaC ensures reproducible environments. Version-controlled infra enables one-command staging and production deploys.
